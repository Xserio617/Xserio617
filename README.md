**Aseprite MCP Server**<br>
Model Context Protocol server in Python that exposes a large Aseprite automation surface: drawing primitives, frame and layer orchestration, palette tooling, quality audits and text rasterization through Pillow. Ships as a container image published to GitHub Container Registry by a GitHub Actions workflow.
